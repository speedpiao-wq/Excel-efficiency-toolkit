第一次安装

下载加载项从本项目 GitHub Release 下载最新 `.xlam`。
打开加载项管理Excel → 文件 → 选项 → 加载项；底部选择“Excel 加载项”→ 转到。
浏览并勾选选择下载的 `.xlam` 文件并勾选。
固定到顶部打开“加载项”选项卡，右键“一键格式化”→ 添加到快速访问工具栏。

每天怎么用

选中文本框边框按住 Ctrl 可以选择多个文本框。
点击“一键格式化”字号、粗体、字体颜色和填充颜色立即统一。
需要调整时打开“格式设置”输入颜色如 #0033CC，保存后跨工作簿继续使用。

加载项不会改变文本框内容、位置、大小和边框，也不会上传工作簿数据。

遇到宏被阻止

不要开启“启用所有宏”。确认文件来自本项目官方 Release 且校验值一致后，可以右键文件 → 属性 → 解除锁定。企业环境请联系 IT 管理员。
