# Beginner-friendly delivery

When the recipient is not technical, lead with the outcome and show only the actions they must take.

## Minimum guide structure

1. **这是什么** — one sentence describing the repetitive task the button replaces.
2. **安装一次** — Excel → 文件 → 选项 → 加载项 → 管理“Excel 加载项” → 转到 → 浏览 → 勾选。
3. **固定到顶部** — open the add-in's Ribbon tab, right-click the main button, choose “添加到快速访问工具栏”.
4. **每天怎么用** — select the object border, optionally Ctrl-select multiple objects, click the top button.
5. **修改设置** — open the settings button, change values, save, then use the main button.
6. **更新或卸载** — close Excel before replacing the file; uncheck it in the Excel Add-ins dialog to disable it.

## Presentation rules

- Use the exact Chinese labels that appear in the add-in.
- Show one action per screenshot or animation beat.
- Explain hexadecimal colors with one example: `#0033CC`.
- Put security troubleshooting after the normal path so it does not frighten first-time users.
- Never tell users to enable all macros globally. For a blocked downloaded file, explain Windows Properties → Unblock only for a file they trust.

## Short-video outline

For a 60–90 second tutorial: before/after problem (5s), install (20s), pin the button (10s), configure (15s), format one and multiple text boxes (15s), update/uninstall reminder (10s). Use cursor highlights and captions; narration is optional.
